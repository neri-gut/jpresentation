# Proposal: Calidad única + plantillas de evento

## Intent

Un `video_quality` de perfil para todo MP4 (`best` incluye 1080p). Plantillas de sistema (entre semana, fin de semana, visita de circuito) y plantillas de usuario para eventos; se aplican a una fecha cuando el operador las elige.

## Scope

`perfiles`, `canciones`, `multimedia`, `proveedor-medios`, `cronometro`.
